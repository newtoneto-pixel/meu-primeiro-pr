# meu-primeiro-pr

Repositório de prática para aprender o fluxo de contribuição no GitHub: criar um branch, fazer uma alteração e abrir um Pull Request.

## Sobre

Este repositório foi criado como exercício para dar os primeiros passos com Git e GitHub:

1. Criar um branch a partir da `main`
2. Fazer uma pequena alteração
3. Enviar (`push`) o branch para o GitHub
4. Abrir um Pull Request para revisar e mesclar a alteração
